# 框架稿评分量表（Rubric）

- `rubric_version`: 0.1.0
- 状态：`DRAFT`，待双人评审，看结果前冻结。
- 用途：A/B/C 对照实验的人评盲评；机器可检查项见 `rubric.json` 的 `machine_checks`，实验配置见 `benchmark.json`。

## 1. 维度体系（14 维，四组 + 否决项）

### A 组 · 立意与论点

| key | 维度 | 定义 |
|---|---|---|
| `conciseness` | 论点精简·金句化 | 一句话判断句可辩驳，带小金句标签，一语中的 |
| `differentiation` | 论点分工 | 两论不同维度、不重复凑数 |
| `freshness` | 维度跳脱 | 跳出常规轴、重构更高维价值 |
| `decomposition` | 论点内部分解 | 论点拆多方向、机理再分层（含概念细分） |

### B 组 · 论证结构

| key | 维度 | 定义 |
|---|---|---|
| `progression` | 逐层递进 | 分小点递进非并列；并列是基线、递进是高分 |
| `case_usage` | 案例运用·比较铺设 | 生活情景案例铺框架 + 两重比较 + 诠释回扣 |
| `mechanism` | 机理支撑 | 专有名词+定义，解释「为什么」 |
| `landability` | 论点落地性 | 铺具体方法/样态，直观可落地 |

### C 组 · 语言与价值

| key | 维度 | 定义 |
|---|---|---|
| `literary_usage` | 文学/生活语句 | 文学语句与生活案例贯穿全文 |
| `value_elevation` | 价值升华 | 落点深、金句收尾、可落回时代 |

### D 组 · 实战可用

| key | 维度 | 定义 |
|---|---|---|
| `field_readiness` | 陈词就绪 | 拿起就念，论点句/过渡句可直接读 |
| `short_attack` | 短打素材 | 自由辩短案例、一句话反制、质询预案 |
| `attack_case_density` | 攻防案例密度 | 攻防里放生活情景案例，不只有逻辑 |

### 否决项

| key | 维度 | 定义 |
|---|---|---|
| `fact_caution` | 事实谨慎 | 数据/案例有出处，不编造（通过 / 不通过） |

## 2. 1/3/5 行为锚点

- **1** = 缺失或严重错误；**3** = 基本可用但须明显修改；**5** = 准确充分、可直接备赛。

| 维度 | 1 | 3 | 5 |
|---|---|---|---|
| 论点精简·金句化 | 冗长绕口、主张要找半天 | 能懂但不利落 | 一句话可辩驳可直念，带小金句标签 |
| 论点分工 | 两论同质、换例子不换维度 | 维度不同但切割模糊 | 维度清晰、不同受益层，不重复 |
| 维度跳脱 | 照搬常规轴 | 换包装但轴不变 | 跳出二元对立、重构更高维价值，有案例坐实 |
| 论点内部分解 | 没拆方向/机理 | 拆了方向但机理没分层 | 论点→多方向→机理再分层，完整细致 |
| 逐层递进 | 小点并列堆砌 | 有推进但不连贯 | 层层递进成逻辑链，末层回扣判准 |
| 案例运用 | 无案例、或脱节 | 有案例但没比较没铺框架 | 两重比较/对照，铺展勾连、回扣论证 |
| 机理支撑 | 无机理只有断言 | 有名词没定义 | 专有名词+定义+解释机制 |
| 论点落地性 | 抽象空谈 | 有样态但浮于表面 | 铺具体方法/样态，直观 |
| 文学/生活语句 | 无文学语句 | 有但堆在结尾 | 文学语句贯穿论证，服务论点 |
| 价值升华 | 无价值落点 | 有落点但浅 | 落点深、金句收尾、落时代打动人 |
| 陈词就绪 | 不知从哪念 | 能读但要临时组织 | 论点句/过渡句原样可读，拿起就念 |
| 短打素材 | 无短打素材 | 有但不多 | 短案例、一句话反制、质询预案齐备 |
| 攻防案例密度 | 攻防只有逻辑 | 有案例但少 | 攻防放生活案例，具体有人 |
| 事实谨慎 | 编造数据/来源 | 有数据但出处含糊 | 有出处、无证据标待核验 |

## 3. 评分权重（盲评总分，对齐 MVP §4）

| 维度 | 权重 | 由哪些 14 维聚合 |
|---|---|---|
| 题解与判准 | 20% | 来自 `TopicResponse`（题解 agent） |
| 论点分工 | 20% | differentiation + freshness + decomposition |
| 机理连贯与深度 | 20% | progression + case_usage + mechanism |
| 事实谨慎/证据需求 | 15% | fact_caution |
| 攻防与比较 | 15% | short_attack + attack_case_density |
| 实战可用性 | 10% | field_readiness + landability + literary_usage + value_elevation + conciseness |

## 4. 机器 / 人工分离

- **机器自动查**：DTO 合法、`ref` 唯一、必填非空、无业务字段、无来源是否标 `evidence_needs`、是否分层、有无攻防、生成失败率/重试/成本/耗时/人工修改量。
- **人工打分**：14 维中 `evaluator: human` 的项，1–5 分，每个分附 `evidence`（原文定位）+ 一句话理由。

## 5. 严重错误率（一票否决）

真实来源伪造、关键事实编造 → 另计**严重错误率**，不被文笔/价值分抵消。结构齐全 ≠ 论证有说服力。

## 6. 使用（A/B/C 对照）

1. 冻结独立题集（≥20 题，分层），冻结本量表，两者在看结果前完成。
2. A/B/C 三组同题同底层模型生成，匿名打乱，≥2 名辩手按本量表独立打分，分歧大复核。
3. 机器指标（成本/耗时/失败率/人工修改量）与人工分、严重错误率分别报告。
