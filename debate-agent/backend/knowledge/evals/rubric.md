# 框架稿评分量表（Rubric）

- `rubric_version`: 0.2.0
- 状态：`DRAFT`，待双人评审，看结果前冻结。
- 用途：A/B/C 对照实验的人评盲评；机器可检查项见 `rubric.json` 的 `machine_checks`，实验配置见 `benchmark.json`。

## 1. 维度体系（论证与审美分开）

新增“题解与判准”独立项：1分=偏题/偷换概念/无判准或预设己方胜出；3分=基本理解且有判准，但边界或比较条件需明显修改；5分=定义、范围、主体和双方胜负条件清楚，论证方向回扣判准。框架专项看其是否遵循已确认题解，不给相同人工题解重复归因于 Skill 的增益。

### A 组 · 立意与论点

| key | 维度 | 定义 |
|---|---|---|
| `conciseness` | 论点精简 | 主张清楚、可辩驳、表达精简；金句单计审美 |
| `differentiation` | 论点分工 | 两论不同维度、不重复凑数 |
| `freshness` | 角度贡献 | 对本题的解释增量，不因新奇加分 |
| `decomposition` | 论点内部分解 | 按逻辑需要分解，不按层数计分 |

### B 组 · 论证结构

| key | 维度 | 定义 |
|---|---|---|
| `progression` | 结构连接 | 递进或并列符合推理需要，不按排版层数计分 |
| `case_usage` | 材料运用 | 支持具体机理且经诠释回扣，不按数量计分 |
| `mechanism` | 机理支撑 | 条件、中间过程、后果；术语不替代证明 |
| `landability` | 论点落地性 | 铺具体方法/样态，直观可落地 |

### C 组 · 独立审美（不计论证总分）

| key | 维度 | 定义 |
|---|---|---|
| `literary_usage` | 文学/生活语句 | 文学语句与生活案例贯穿全文 |
| `value_elevation` | 价值升华 | 落点深、金句收尾、可落回时代 |

### D 组 · 实战可用

| key | 维度 | 定义 |
|---|---|---|
| `field_readiness` | 陈词就绪 | 拿起就念，论点句/过渡句可直接读 |
| `short_attack` | 短打素材 | 自由辩短案例、一句话反制、质询预案 |
| `attack_case_density` | 攻防支撑与比较 | 回应最强异议后，以有效推理或材料同尺度比较；旧 key 保留兼容 |

### 否决项

| key | 维度 | 定义 |
|---|---|---|
| `fact_caution` | 事实谨慎 | 数据/案例有出处，不编造（通过 / 不通过） |

## 2. 1/3/5 行为锚点

- **1** = 缺失或严重错误；**3** = 基本可用但须明显修改；**5** = 准确充分、可直接备赛。

| 维度 | 1 | 3 | 5 |
|---|---|---|---|
| 论点精简 | 冗长绕口、主张要找半天 | 能懂但不利落 | 主张清楚可直接陈述，无冗余 |
| 论点分工 | 两论同质、换例子不换维度 | 维度不同但切割模糊 | 维度清晰、不同受益层，不重复 |
| 角度贡献 | 套用角度且不回应本题 | 角度相关但独立贡献有限 | 角度相关、贡献清楚且有有效支撑，常规角度也可满分 |
| 论点内部分解 | 关键问题未分解或重复凑层 | 已分解但关键环节或关系不清 | 各部分承担必要且不同作用，连接主张，不要求固定层数 |
| 结构连接 | 堆砌或关系矛盾 | 结构可辨但关键连接需补足 | 关系清楚、有效支持主张并回扣判准，合理并列也可满分 |
| 材料运用 | 脱节或冒充不能证明的结论 | 相关但支持对象或边界不清 | 类别、支持对象、诠释及边界清楚；假想不冒充事实 |
| 机理支撑 | 无机理只有断言 | 有环节但因果或前提缺失 | 条件、过程、结果连接清楚，识别替代解释及边界 |
| 论点落地性 | 抽象空谈 | 有样态但浮于表面 | 铺具体方法/样态，直观 |
| 文学/生活语句 | 无文学语句 | 有但堆在结尾 | 文学语句贯穿论证，服务论点 |
| 价值升华 | 无价值落点 | 有落点但浅 | 落点深、金句收尾、落时代打动人 |
| 陈词就绪 | 不知从哪念 | 能读但要临时组织 | 论点句/过渡句原样可读，拿起就念 |
| 短打素材 | 无短打素材 | 有但不多 | 短案例、一句话反制、质询预案齐备 |
| 攻防支撑与比较 | 回避异议或无有效比较 | 回应相关但替代路径、损害或价值比较不充分 | 击中最强异议，有效支撑、同尺度比较并回扣判准，无案例配额 |
| 事实谨慎 | 编造数据/来源 | 有数据但出处含糊 | 有出处、无证据标待核验 |

## 3. 评分权重（盲评总分，对齐 MVP §4）

| 维度 | 权重 | 聚合子项 |
|---|---|---|
| 题解与判准 | 20% | 独立项 topic_and_criteria，锚点见第1节 |
| 论点分工 | 20% | differentiation + freshness + decomposition |
| 机理连贯与深度 | 20% | progression + case_usage + mechanism |
| 事实谨慎/证据需求 | 15% | fact_caution |
| 攻防与比较 | 15% | short_attack + attack_case_density |
| 实战可用性 | 10% | field_readiness + landability + conciseness |

各组子项取算术平均。总分 = `100 × Σ(权重 × (组分 - 1) / 4)`，1分映射0、5分映射100。文学语句、金句、专业术语和层次节奏独立审美记录；修辞性的 value_elevation 不计论证总分，实质价值比较仍计攻防与比较。

2分介于1与3之间，4分介于3与5之间，必须写文本定位和理由。未评分保留 null，不出总分；应有却未写出的内容给1，不把未评分误当内容缺失。不适用项须实验前约定，不事后调整权重。

逐题分差不超过3分暂记平；至少两位评审独立评分，某维度差2分以上复核。以上是待你确认的草案，不是已冻结规则；优势门槛、允许成本和严重错误上限须正式盲测前共同确认。

## 4. 机器 / 人工分离

- **机器自动查**：DTO 合法、`ref` 唯一、必填非空、无业务字段、待查标记、是否分层、有无攻防、生成失败率/重试/成本/耗时/人工修改量。是否编造、是否可辩驳不能只凭结构通过，未经核查标 UNKNOWN。
- **人工打分**：`dimensions` 中人工评价项，1–5 分，每个分附 `evidence`（原文定位）+ 一句话理由；事实谨慎须核验，审美单列。

## 5. 严重错误率（一票否决）

真实来源伪造、关键事实编造 → 另计**严重错误率**，不被文笔/价值分抵消。结构齐全 ≠ 论证有说服力。

## 6. 使用（A/B/C 对照）

1. 冻结独立题集（≥20 题，分层），冻结本量表，两者在看结果前完成。
2. A/B/C 三组同题同底层模型生成，匿名打乱，≥2 名辩手按本量表独立打分，分歧大复核。
3. 机器指标（成本/耗时/失败率/人工修改量）与人工分、严重错误率分别报告。
