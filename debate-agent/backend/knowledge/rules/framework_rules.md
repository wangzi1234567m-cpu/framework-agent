# 框架稿写作规则（第二轮，待用户确认）

状态：下表均为 **AI 从原稿推断的待审规则**，不是已确认的项目要求；**用户确认规则：无**。原稿中的数字、引文和案例均未外部核验。“依据”只表示原稿有该写法，不表示事实或论证成立。新版重点参考三份转换稿：M1 松弛感 MD、M2 爱可量化 MD、M3 传统就业与 OPC MD。文件全名及其他样本见 [新报告](../annotations/analysis_report_md_update.md) 和 [manifest](../examples/manifest.json)；定位 `line:N` 为对应 MD 原始行。
