## 范围与口径

扫描位置：`debate-agent/` 的上一级目录，仅扫描其**直接子文件**；截至本次运行，共 8 个正式稿件文件（4 MD、3 DOCX、1 PDF），另 3 个 `~$*.docx` 为 Word 临时锁文件，跳过并记录于 [manifest.json](../examples/manifest.json)。解析失败 0 份。S1/S2 同名但格式不同，文字相似而不完全相同，**按两个原始文件保留**；按辩题计，可能是 7 组稿，待确认。

**原稿事实**在本报告中指“原稿确实如此表述”，不表示所述事件、数字、研究真实或因果成立。**AI 推断**指跨稿归纳或由论点推测立场；**用户已确认规则：无**。JSON 中 `raw_units` 保存提取到的文字及行/段/页定位，`sha256` 指向未改动的原文件；每个自动分类字段是可复核的**候选片段**，没有标签的案例或跨行数据可能漏掉。MD 内嵌 base64 图片只留位置标记，DOCX 内嵌媒体不做 OCR；PDF 只读文字层，均不能声称已读懂图片。

## 跨稿比较（AI 推断）

- **共同结构**：多数样本先界定关键词/背景，再展开两条主论，每论旁置机理与资料，另有攻防；判准、价值和环节安排并不齐全。依据 S3 `line:15-44,82-184`、S4 `paragraph:2-17,27-36`、S5 `paragraph:6-29,62-115`、S8 `line:1-59,142-334`；不能据此宣布固定模板。
- **论点设计**：S4 按个人/社会尺度，S5 按生存兜底/长期成长，S8 按效率/实惠，S1 按自我/他人压力拆分；S3 按工作能力/生活质量拆分。各论点所用比较轴不同（对应论点位置见上表）。
- **机理展开**：S4 从假设量化值到识别与行为反馈（`paragraph:17-25`）；S5 从产品能力到销售渠道/信任再到变现（`paragraph:34-59`）；S8 从工厂预处理到门店缩短备餐时间（`line:100-125`）；S3 用认知资源解释工作效率（`line:88-106`）。这些是**稿内因果链**，并非本项目验证的因果研究结论。
- **差异**：S4 偏脑洞设定与密集预反驳，几乎无统计引文；S5、S8 倾向调查、报道和经营链条；S1 有环节安排、自由辩讲法与丰富场景；S6/S7 有未完成判准或待补内容。S1/S2 是疑似同稿不同载体，不应当算作独立的两个写作风格样本。
