**原稿事实**表示“这些文字实际出现在相应原稿里”，不代表数字、引文或事件已核实。**AI 推断**表示下文的归纳和跨格式关联；**用户确认规则目前仍为零**。Markdown 的 `line:N` 指其原文件行号，Word 的 `paragraph:N` 指 `word/document.xml` 段号。每份独立原件的 SHA-256、逐行文字与结构化候选字段均在 [样本索引](../examples/manifest.json) 所指向的 JSON，三份旧格式并未合并或覆盖。

当前共 **11 份正式文件**（7 MD、3 DOCX、1 PDF），另有 **2 个** `~$` Word 临时锁文件，解析失败 **0**。这约是 7 个辩题/稿件族，不等于 11 份独立写作样本：M1、M2、M3 分别与旧格式有相近标题；内容是否完全相同，未逐字鉴定。根目录未提供转换稿引用的 `assets/`，因此所涉图片的文字仍不可读。

## 逐稿细读

### M1 松弛感

- **持方与判准**：标题标“反”（`line:1`），稿内论点及自由辩努力证明“更轻松”（`line:104,145,216,225`）；没有单列“判准”标题。定义松弛感为面对压力时从容、善待自己，并区分“不等于躺平”“强调不等于怪罪”“不是时刻松弛”（`line:24-85`）。将“是不是更轻松”视作稿内实际比较方向是 **AI 推断**，不是形式化判准已被用户确认。
- **论点与机理**：第一论是自我苛责/紧绷 -> 休息有正当性 -> 身心轻松（`line:104-143`）；用“自杀式上进”“压力上瘾”描述困境，并放入正念干预及工作场景（`line:108-143`）。第二论是他人审视 -> 改变对评价的态度 -> 自洽充盈（`line:145-204`）；穿搭、旅游、育儿各有 Before/After（`line:149-181`），后面再给方向和“肢体反馈假说”等方法提示（`line:183-204`）。
- **案例/数据/来源**：引《2025年职场人请假报告》、益普索与所谓正念研究等（`line:90-102,131-139`）；有张雪峰、白岩松、社媒帖子、中国传媒大学访谈等个案或讲法（`line:108-124,149-181`）。**原稿列出**点赞数及研究效果；本报告没有验证其真实性，也不能由社媒个例推出普遍效果。
- **攻防与临场**：开篇先处理“被消费主义利用”“松弛就是躺平”等误读（`line:28-84`）；自由辩将旅行、育儿场景压缩为问句/结论（`line:206-232`）；正式攻防承认极端生存压力的覆盖边界，再反诠释日常情境并处理消费主义（`line:240-291`）。还有环节时间和外部链接（`line:5-20`）。
- **无法判断**：个别字形为“松总感/松总”，转换后仍如此，不擅自校正；所引研究、点赞、访谈是否可复核；`assets/` 引用的图标和图片不可读。DOCX/PDF 文字与此相近，但绝非据此认定完全一致。

### M2 如果爱可以量化

- **持方与判准**：标题明说“是人类的幸运”（`line:1`）；“幸运/不幸”的评价标准是增强对自我及外界的掌控，火、体重秤和疫情为原稿用来说明标准的例子（`line:9-23`），不是本项目验证的历史因果。
- **论点与机理**：第一论覆盖亲密关系（减少误会、以量化曲线帮助经营），分别写 `step1/step2` 并辅以爱情骗子、错过彼此、体重秤类比（`line:25-40`）；第二论覆盖社会职能（岗位需要关爱 -> 缺乏关爱可能造成伤害 -> 筛选/监督），用三步链和幼师/护工情景（`line:53-73`）。稿内案例有具体伤害事件与数字（`line:65-69`），未附可直接核验的出处。
- **攻防特色**：两论后分别预反驳（`line:42-51,75-99`）；独立“反驳”展开隐私/统一标准/测量准确性、个性化、攀比、痛苦、朦胧美和“大小波动无需量化”等异议（`line:101-178`）。原稿采用“问题非量化造成，而是量化揭示”的属性拆解，拿 CT 作类比（`line:128-141`），再回到掌控与经营关系的价值比较。这里是 **稿内论证方法**，不等于可测量“爱”的技术事实。
- **来源与缺口**：正文几乎不用可直接追溯的研究来源；“避免错过”情景在 `line:33` 句子未完成；统一测量、准确性、隐私等是对脑洞题的设定推演（`line:103-114`），不是既有现实条件。需要明确区分设定内假设、真实个案与类比。

### M3 传统就业与 OPC

- **持方与判准**：标题直接主张传统就业更能实现职业价值（`line:3`）；定义 OPC/传统就业并引价值观量表、多维职业价值（`line:5-12`），背景以报酬、成长、稳定及 OPC 竞争的稿内调查构建比较需求（`line:14-30`）。没有独立写出“如何在各维度权衡”的判准。
- **论点与机理**：第一组正文以“个人承担风险/企业兜底”为比较起点（`line:36-41`），依次写个人能力高度依赖、获客与信任缺口、AI 产品同质化，并配【数据】、【机理】、采访和【讲法】（`line:43-77`）；第二组将“OPC 兑现能力而非培养能力”和企业导师、项目平台对比（`line:81-104`）。Word 原件的主论标题分别是稳定兜底与体系化成长（`paragraph:29,62`），**但 M3 的两处标题位于图片引用 `line:34,79`，不能说这些标题已经从 MD 中读取**。
- **案例/数据/攻防**：稿内引用 SoloNest 调查、媒体采访、王乐宇/王超个案（`line:38-73`），京东、格力、TCL 培养例子（`line:88-104`）；自由辩讨论 OPC 一人分饰多角与工作生活平衡（`line:106-122`）；攻防回应政策扶持、创业门槛降低和“做喜欢的事”（`line:124-159`）。这些媒体名称、比例与因果链均未外部核验。
- **转换缺口**：`line:1,34,79` 的图片路径指向未提供的 `assets/` 文件；其中 `line:34,79` 位于主论标题位置，导致 M3 的自动结构化 `arguments` 为 0。这是**解析能力/源文件缺失**，不是“原稿没有论点”；Word 版有两个标题，但在 JSON 中保持独立来源。`line:23-25,144-146` 还有跨行断句，自动片段可能被切开。
